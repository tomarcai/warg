Anonymous Subversion

Run the following commands in a directory that you have write access to (such as your home directory):

Desktop (J2SE) Domination

svn co https://svn.code.sf.net/p/domination/code/Domination

please use Netbeans/Ant to build the project. From Netbeans open "swingUI" as the project.

Browse Subversion Repository

iOS & Android Domination

svn co https://svn.code.sf.net/p/domination/code/Domination
svn co https://svn.code.sf.net/p/swingme/code/UtilME
svn co https://svn.code.sf.net/p/swingme/code/SwingME
svn co https://svn.code.sf.net/p/swingme/code/iOSME
svn co https://svn.code.sf.net/p/swingme/code/AndroidME

Please use Android Studio 3.2.1 to 2025.1.1 Patch 1/Gradle to build the project

iOS setup: you will need to have cocoapods installed and run "pod install" from 'Domination/ios/xcode' then you will need to revert the 'ChartDataSet.swift' file.

To run on iOS from Android Studio you will need to enable the experimental feature "Configure all Gradle tasks during Gradle Sync (this can make Gradle Sync slower)"
